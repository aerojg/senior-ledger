# 가계부자 원격 시험 키트 v1

작성일: 2026-11-03 / 대상: 아내, 직장 지인 (총 2명) / 방식: 얼굴을 볼 수 없는 통화 시험 / 소요: 한 사람당 30분 안팎

구성: 0. 시험 전 준비 / 1. 동의 문구 / 2. 과제 카드 5+1장 / 3. 기록표 / 4. 시험 뒤 정리

---

## 0. 시험 전 준비 (마초)

시험 전날까지 아래를 끝낸다.

1. 앱 주소를 참여자에게 카톡으로 보내 둔다. 주소는 시험 시작 직전에 보내도 된다.
2. 아래 "시험용 은행 문자"를 참여자에게 문자(또는 카톡)로 보내 둔다. 날짜 부분은 시험 당일 날짜로 고친다. 당일 날짜여야 5번 과제의 결산 숫자가 맞는다.
3. 이 문서의 과제 카드를 카톡으로 한 장씩 보낼 수 있게 복사해 둔다. 전화로 읽어 줘도 된다.
4. 기록표를 사람마다 한 부씩 출력하거나 화면에 열어 둔다. 사람 이름은 쓰지 않고 A, B로만 적는다.
5. 참여자의 폰 종류를 미리 확인한다. 안드로이드는 크롬, 아이폰은 사파리로 앱을 연다.

시험용 은행 문자 (날짜만 시험 당일로 고쳐 보낸다)

```
[Web발신]
신한11/03 12:10
110-***-123456
출금 12,300
잔액1,500,000
가나다식당
```

통화 방법

- 스피커폰이나 이어폰으로 통화를 이어 둔다. 참여자는 폰을 손에 쥔다.
- 화면 공유(카카오톡 영상통화)가 되면 쓰되, 참여자에게 부담이 되면 하지 않는다.
- 마초는 도와주지 않고 듣고 적는다. 화면은 볼 수 없으므로 "지금 화면 맨 위에 뭐라고 쓰여 있어요?"를 자주 묻는다.

도움 규칙 (모든 과제 공통)

- 30초 멈추면: "지금 어디를 찾고 계세요?"만 묻는다.
- 1분 넘게 막히면: 힌트 1단계를 한 번 준다. 그래도 안 되면 힌트 2단계를 준다.
- 힌트 2단계를 써도 안 되면 직접 알려 주고 기록표에 "실패"로 적는다.
- 무엇을 도왔는지 기록표 "도움" 칸에 적는다 (0 = 도움 없음, 1 = 힌트 1단계, 2 = 힌트 2단계, 3 = 직접 알려 줌).

## 1. 동의 문구 (통화 시작할 때 마초가 읽는다)

### 1-1. 공통 문구

> 오늘 시험은 제가 만든 가계부 앱이 쉬운지를 보는 시험이에요.
> 앱을 보는 시험이지 ○○님을 평가하는 시험이 아니에요. 못 하시거나 헷갈리시는 건 앱이 부족한 거예요. 그래서 막히시면 오히려 제게 큰 도움이 돼요.
> 진짜 가계 정보는 넣지 않아요. 제가 알려 드리는 가짜 숫자만 쓰세요.
> 쓰신 내용은 폰 안에만 있고 제게 오지 않아요. 화면을 녹화하거나 사진으로 찍지도 않아요.
> 통화하면서 제가 메모는 해요. 이름은 적지 않고 A, B로만 적어요.
> 하시다가 언제든 "그만할게요" 하시면 바로 멈춰요. 괜찮으실까요?

참여자가 "네"라고 답하면 기록표 맨 위 "동의" 칸에 ○를 적는다.

### 1-2. 직장 지인용 추가 문구

> 시험 결과는 앱을 고치는 데만 쓰고, 이름은 어디에도 남기지 않아요. 직장이나 다른 분께 이야기하지 않을게요.

### 1-3. 시작 전 한 가지 부탁

> 하시면서 화면에 보이는 걸 소리 내어 말해 주세요. "지금 이렇게 보여요", "이걸 눌러 볼게요"처럼요. 제가 화면을 못 보니까 눈이 되어 주세요.

## 2. 과제 카드 5+1장

카드의 굵은 글씨 부분만 참여자에게 읽어 주거나 카톡으로 보낸다. 나머지는 마초만 본다.

### 카드 1. 앱 설치하고 처음 안내 넘기기

참여자에게:

**주소를 눌러서 앱을 열고, 폰에 앱을 설치해 주세요. 처음 나오는 안내는 끝까지 넘겨 주세요.**

성공 기준: 처음 안내를 마치고 "홈" 화면이 보인다.

막힘 신호: 주소를 눌러도 앱이 안 열림 / "설치" 단추를 못 찾음 / 처음 안내에서 멈춤.

힌트 1단계: 안드로이드는 "크롬 오른쪽 위 점 세 개 → 앱 설치(또는 홈 화면에 추가)"를 찾아보라고 말한다. 아이폰은 사파리 아래 공유 단추 → "홈 화면에 추가".
힌트 2단계: 설치는 건너뛰고 크롬(또는 사파리)에서 열린 상태로 시험을 계속한다. 설치 단계는 "실패"로 적는다.

마초가 확인할 것: 설치 단추를 스스로 찾았는지 / 처음 안내를 읽는지, 그냥 넘기는지 / 글자 크기가 읽기 괜찮다고 하는지.

### 카드 2. 오늘 쓴 돈 기록하기

참여자에게:

**오늘 점심으로 8,000원을 썼다고 해 볼게요. 앱에 기록해 주세요.**

성공 기준: 홈에서 시작해 "식비" 같은 알맞은 분류로 8,000원을 쓴 돈으로 기록한다. 기록했다는 확인 화면이 보인다.

막힘 신호: 기록을 어디서 시작하는지 모름 / 쓴 돈과 받은 돈을 헷갈림 / 분류를 못 고름 / 금액 칸에서 헤맴.

힌트 1단계: "홈 화면에서 기록하는 단추가 있는지 찾아보세요"라고 말한다.
힌트 2단계: "[직접 쓰기]를 눌러 보세요"라고 말한다.

마초가 확인할 것: 처음 눌러 본 단추가 무엇이었는지 / 분류를 고르는 데 걸린 시간 / 금액이 8,000원으로 맞게 들어갔는지 소리로 읽어 달라고 한다.

### 카드 3. 받은 돈 기록하기

참여자에게:

**이번에는 월급 200만 원이 들어왔다고 해 볼게요. 앱에 기록해 주세요.**

성공 기준: 받은 돈으로 200만 원을 기록하고 "급여"에 해당하는 분류를 고른다.

막힘 신호: 쓴 돈 화면에서 그대로 진행하려 함 / "받은 돈"을 못 찾음 / 분류 이름이 낯설어 멈춤.

힌트 1단계: "돈이 나간 게 아니라 들어온 돈이에요"라고 말한다.
힌트 2단계: "[받은 돈]을 눌러 보세요"라고 말한다.

마초가 확인할 것: 카드 2와 비교해서 더 쉽게 했는지, 헤맸는지 / 금액 입력 칸에서 0을 몇 개 쓰는지 헷갈리는지.

### 카드 4. 은행 문자 붙여 넣어 기록하기

참여자에게:

**제가 보내 드린 은행 문자를 복사해서, 앱에 붙여 넣어 기록해 주세요.**

성공 기준: 문자를 복사해 앱 홈의 [문자 붙여넣기]에서 붙이고, 확인 카드에서 금액과 가게 이름이 맞는지 보고 저장한다.

막힘 신호: 문자를 길게 눌러 복사하는 방법을 모름 / [문자 붙여넣기] 단추를 못 찾음 / 붙여 넣은 뒤 다음으로 못 감 / 확인 카드의 질문(예: 쓴 돈/받은 돈, 분류)을 이해하지 못함.

힌트 1단계: "문자 글자를 길게 꾹 누르면 복사가 나와요"라고 말한다.
힌트 2단계: "앱 홈에 [문자 붙여넣기]가 있어요. 그걸 눌러 보세요"라고 말한다.

마초가 확인할 것(가장 중요): 복사하는 과정에서 막혔는지 / 확인 카드의 금액(12,300원)과 가게 이름(가나다식당)을 소리로 읽게 하고 맞는지 확인 / 쓴 돈으로 자동 분류된 것을 이해하는지 / 결제 방법을 고르는 칸에서 헷갈리는지.

### 카드 5. 기록 고치고 이번 달 결산 보기

참여자에게:

**처음 기록한 점심 8,000원을 9,000원으로 고쳐 주세요. 그다음 아래 메뉴의 [결산]을 눌러서, 이번 달에 쓴 돈과 들어온 돈이 얼마인지 말해 주세요.**

성공 기준: 점심 기록을 찾아 금액을 9,000원으로 고친다. 결산 화면에서 "쓴 돈 21,300원, 들어온 돈 2,000,000원"을 읽어 말한다. (9,000 + 12,300 = 21,300)

막힘 신호: 기록을 어디서 찾는지 모름 / 고치기와 지우기를 혼동 / 결산 화면의 숫자 중 어느 것이 "쓴 돈"인지 모름 / 숫자를 읽어도 뜻을 모름.

힌트 1단계: "홈에서 [내역 보기]로 가면 방금 쓴 기록들이 있어요"라고 말한다.
힌트 2단계: "점심 기록을 눌러 보세요. 고치는 화면이 나와요"라고 말한다.

마초가 확인할 것: 숫자를 맞게 읽었는지 / "이게 무슨 뜻인지 설명해 달라"고 하면 이해하는지 / 결산 화면이 길고 복잡하다고 느끼는지 / 글자와 단추 크기.

### 카드 +1 (선택). 저금통에 모으기

시간이 남고 참여자가 여유 있어 할 때만 한다.

참여자에게:

**아래 메뉴의 [저금통]을 눌러서, 칸을 하나 만들고 5만 원을 저금해 보세요.**

성공 기준: 칸을 하나 만들고 5만 원을 저금해서 저금통 화면에 반영된 것을 확인한다.

막힘 신호: 칸 만들기를 못 찾음 / 용어(미리 떼어 둔 돈 등)를 이해하지 못함 / 저금하는 단추를 못 찾음.

힌트 1단계: "저금통 화면에서 칸을 만드는 단추를 찾아보세요"라고 말한다.
힌트 2단계: "저금통 화면 안의 [저금했어요] 단추를 눌러 보세요"라고 말한다.

마초가 확인할 것: 저금통이 무엇인지 설명 없이 이해하는지 / "미리 떼어 둔 돈"이라는 말이 이해되는지.

## 4. 시험 뒤 정리

1. 참여자에게 감사 인사를 한 줄 보낸다.
2. 막힌 화면이 있었다면 참여자에게 그 화면 스크린샷을 한두 장 보내 달라고 부탁한다. 스크린샷은 시험 이후 확인용이며, 가계 정보가 없는 가짜 화면이다.
3. 참여자 폰에 남은 시험 기록은 가짜이므로 그대로 두거나 앱을 지워도 된다고 말씀드린다.
4. 기록표 두 장을 모아 마초가 클로드에게 보내 준다 (사진 또는 글).
5. 클로드가 막힌 지점 목록과 개선안으로 정리한다. 막힘이 두 사람 모두에게 나온 곳을 먼저 고친다.

### 해석할 때 주의

- 두 사람 모두 막힌 곳은 앱의 문제일 가능성이 높다. 한 사람만 막힌 곳은 그 사람의 폰 사용 수준 때문일 수 있다.
- 말로는 "괜찮다"고 해도 기록표에서 "도움 2~3" 또는 "시간이 오래 걸림"이었다면 막힘으로 본다.
- 이 시험은 큰 막힘을 거르는 1차이다. 결산 심층(연간 결산, 은퇴 후 생활비)과 가족 밖 시니어 시험은 이후에 별도로 한다 (Q72, 시험 항목 22).
