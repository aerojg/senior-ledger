# 가계부자 (gagyebuja)

시니어를 위한 무료 가계부 웹앱이다. 이 저장소(senior-ledger)는 가계부자의 소스 코드를 담고 있다.

## 소개

어렵지 않게 쓰고, 한 달을 마치면 쉬운 말로 풀어 주는 가계부를 만든다. 은행 문자를 붙여 넣으면 기록이 쌓이고, 아낀 돈은 가상의 저금통에 모인다.

## 현재 상태

개발 중이다. 첫 번째 시험판(MVP)을 만드는 단계이며, 앱 주소는 공개 준비가 끝나면 이곳에 적는다.

## 개인 정보

이 앱은 로그인과 서버가 없다. 입력한 기록은 사용자의 휴대폰 안에만 저장된다. 이 저장소에는 코드와 공개해도 되는 문서만 올리며, 실제 소비 내역과 계좌 정보 같은 개인 정보는 올리지 않는다.
